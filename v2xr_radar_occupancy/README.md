# V2X-R 雷达占用、真值注入与误检归因

唯一入口为 run_all.sh。在海光后台执行。实验使用独立输出目录 /data/cjm/datasets/logs/v2xr-radar-occupancy-v1/。卡 1 跑 D1，卡 2 跑 Fog 真值注入，卡 3 跑 Snow 真值注入。文件字段扫描和误检归因使用 CPU。

- 字段扫描逐场景枚举海光已有的 V2X-R train、validate、test 原始 7z 包，临时提取其中的 *_radar.pcd 后统计实际头部字段、类型和格式。报告列出每个包。覆盖范围以服务器现存包为准。
- D1 在 F0 的 0.4 米鸟瞰网格上使用固定 Clean 真值框的水平投影。每帧在主车坐标中合并参与车的传感器点。主表使用原加载器投影和视野过滤后的点，另列实际保留柱点及 GSPR 加权点质量。GSPR 有正可靠性下限，因此对保留柱按加权质量大于 0 二分时，占用与保留点表相同。按场景成组重采样估计 Fog 雷达占用的概率差区间。
- D2 保持 F0 第 20 轮正式权重和原始评分代码。只在固定真值框内、所有参与车都无 LiDAR 保留柱、至少一车有真实 Radar 柱的网格做注入。对有雷达柱的车辆把相同位置的 64 通道雷达特征复制到空 LiDAR 通道。用现有 F0 正式结果作同权重参照。两个天气任务各算一遍 Clean，以满足冻结评测器对 F 协议的固定真值缓存要求。这个实验衡量指定特征复制规则的真值选位收益，范围限于该规则。
- D3 复用 F3 第 10 轮前 120 个 Fog 帧。按 F 协议 0.7 阈值筛出误检，再以同帧鸟瞰框重叠至少 0.5 做按重叠度降序的贪心一对一配对。由开启 Radar 时未配对的误检按固定种子抽 50 个。用原始 Fog 加载器读取所需帧，分别统计框中心所在网格及周围 3×3 网格的 LiDAR 点数。空间归因描述误检与 LiDAR 占用的共现关系。

结果文件为 PCD_FIELDS.json、D1.json、D2_fog.json、D2_snow.json、D3.json。进度和错误见同目录下各任务日志和 launch.log。
