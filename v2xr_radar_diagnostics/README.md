# 冻结权重雷达诊断

在海光执行 run_all.sh。默认用物理卡 5。可用 GPU 环境变量指定独立空闲卡。脚本拒绝卡 1，训练目录仅作为输入。结果写入 /data/cjm/datasets/logs/v2xr-radar-diagnostics-v1/。

顺序为真实帧恒等性检查、F2 原始逐柱观测、F3 训练配对审核、已有 F3 缓存重统计、F2 支持度干预。F2 第 16 轮在固定的前 120 个 Clean 和 Fog 帧运行，样本和干预均预先确定。固定真值逐帧核对。F3 只读第 10 轮权重、前十轮辅助训练记录和已有第十轮诊断。配对审核在训练集中按索引等间隔取 48 帧，使用现有采样和标签代码。前景指雷达柱质心落在本车天气过滤前标注框的水平投影内。

D0 保留原支持度，D1 取平方根，D2 在真实占用柱设为 1。三组只改变 R-B 残差末端的乘数，R-A 残差、门控输入及门控值沿用原支持度。初始验收对真实占用、空雷达、原模型 D0 数值等价（绝对与相对容差各 1e-5，并记录原模型重复前向差异）和残差比例逐项检查。目标附近定义为真值框水平投影向外扩 0.4 米，检查实际雷达柱质心。受损目标为相对 Clean 点数下降至少 30% 且仍有雷达点的固定真值目标。

INTERVENTION_CHECK.json 记录启动前验收。D0、D1、D2 子目录的 RESULT.json、feature_rows 和官方评测文件记录逐邻居数和逐目标证据。PAIR_AUDIT.json 保存训练样本及日志统计。F3_CACHED_COUNTS.json 保存 TP、FP、FN 和置信度分布。误检无真值身份，计入全局。SUMMARY.json 汇总三种干预和固定目标配对结果。
