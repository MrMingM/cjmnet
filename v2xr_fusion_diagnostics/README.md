# P0 AttFuse 三项固定权重机制诊断

入口在海光上执行。日志、逐帧统计和总报告写到数据盘。

```sh
r=/data/cjm/datasets/logs/v2xr-fusion-diagnostics-v1
mkdir -p "$r"
nohup sh /home/cjm/OpenCOOD-main/cjmnet/v2xr_fusion_diagnostics/run_all.sh >> "$r/launch.log" 2>&1 < /dev/null &
```

运行前审计原始 P0 权重、官方运行代码、数据清单、上一轮 327 个目标身份及逐帧干预记录。三组先分别在物理卡 0、2、4 完成数值单元测试与三天气真实输入自测，统一通过后并行运行。同一命令可按源码合同与逐帧哈希续跑。

- D1 在原始主车查询和同位置跨车点积下，分别替换注意力矩阵和邻车值特征。三尺度联合模式在全量评测，单尺度独立替换在已知丢失目标所在帧执行。独立替换的记录含每目标检测状态。
- D2 在原融合输出处逐尺度替换为原始单车 AttFusion 或局部 Clean 干预输出，并以真实单车输入单列对照。全模式每种天气各 829 帧。
- D3 对主车、邻车和双方分别执行 LiDAR 上下文与 Radar 存在的双因素对照。检查 64 通道两路编码、128 通道拼接和三个融合尺度。Radar 关闭使用原生空柱分支。

历史目标帧复用上一轮 12 米并集和受保护柱体定义。其他帧从固定真值中按距离固定选取首个目标。Clean 天气直接使用相同输入作为空干预。背景格取所有固定目标覆盖格的补集，按距离分层。完整 O、O*、F 使用 LR0 预处理、后处理和官方匹配与计分函数。干预区域与评分标签只在离线实验使用。

逐帧 JSON 保存全部目标、各层区域能量、车辆数和恢复状态。已知丢失目标帧另有 NPZ 保存目标覆盖格和确定性采样背景格的原始张量。D1 注意力矩阵按位置、查询车辆、参与车辆存放。原始整图特征即时计算后归纳为分层统计，避免全量重复存储。各组日志为 `smoke.log` 和 `full.log`。
