# 假设、近似与证据等级

## 简单版

本轮把已有晴天回波变弱，再检查不同车保留了多少证据。能验证计算是否一致；缺少传感器实测时，无法由此证明雾天物理真实性。

| 等级 | 当前内容 |
|---|---|
| 数学模型保证 | alpha非负且有界；同一场相同world位置相同alpha；静态场；查询无状态 |
| 合成数值检查 | 反变换、跨车坐标、yaw/顺序、零/常数/分层积分、反向积分、收敛、确定性、散射核；实际次数见运行报告 |
| 服务器门禁待验证 | 真实时间戳/轨迹、跨车GT ID/角点、RGB编码、PCD回读、E0点索引来源、NumPy批处理与标量一致性 |
| 独立设计的近似 | 32模式tanh随机场、静态天气、大尺度浓度、GT框内回波的目标关联、固定诊断阈值 |
| 未校准 | alpha=.06的本数据真实性、25m长度、contrast=.8；强度是否线性对应功率；接收阈值、beta-alpha关系、噪声与增益 |
| 当前不实现 | 非均匀soft波形/多次散射、雨雪、模型训练/AP、逐束扫描重建 |
| 无法从已有文件恢复 | 未返回/被遮挡射线、真实扫描线ID、逐束时间、真实发射功率、完整回波波形和传感器检测门槛 |

## 进一步理解

1. **clear-return-conditioned simulation**：以晴天已经记录下来的回波为条件进行模拟。缺失的晴天射线和遮挡后物体无法补回。全车原本就没点的目标与天气导致证据下降需分开报告。
2. 原始回波来源指“从原晴天点延续下来”；它不证明一定击中真实车辆表面。只有Clean GT框，没有逐点语义真值，框内计数是目标关联代理，地面/边界误归属仍可能存在。
3. 模拟点即使落入GT框，也保持simulated来源；不计入真实回波保留数。移出框的soft点仍可追溯其原始射线索引。
4. **physical observability**在这里表示原始回波证据的数量与衰减代理。大于N个点不能保证detector能检出。A/B按预注册count阈值表示证据不足，同时单独保存真正零点标志；C/D使用连续强度比例。混合情况保留residual类别，避免强制四分类。
5. effective_intensity_ratio是保留hard点的量化前强度和 / 原框内Clean强度和。原始强度和为0时记null，不能设成0或1制造差异。另存数量比例、平均透射率、距离与视角。
   attenuation_only的retained计数表示点记录保留；即使写盘强度量化到0，也不擅自推断传感器是否会接收到它。因此该计数不能当作已预测的真实传感器存活回波数。经验阈值计数仅作未校准敏感性诊断。
6. 当前静态场不能支持雾团风速或逐束时间研究。时间索引只用于同步各CAV，不将`000068`当成68秒。
7. GT的location+center加法直接继承OpenCOOD标签约定；程序检验其自洽与跨车一致，无法独立证明它等同真实世界安装标定。
8. 统计按scene组织。连续帧不能当独立样本；不足5个scene不生成bootstrap区间。最小版每分区2个scene，只能作描述性验证。
9. 工程门禁通过不称物理真实性已证明。非均匀场、共享粒子和协作补偿已有研究。本轮尚未建立新的检测失败模式结论。

任何新参数必须在generator development分区依据物理统计制定，先使用新配置/输出目录冻结；physics validation只报告，future model分区本轮不生成，不读PCD。禁止通过检测AP选择seed、场形状或阈值。
