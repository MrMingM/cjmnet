# 本次回波模型能够说明什么

这次修复让雾有机会抢占目标回波，并产生错误距离或无返回。
接收器先看到目标脉冲和沿途散射的叠加，再选择峰值。
它是有明确方程依据的**单次散射、相对信号原型**；OPV2V 的真实接收器尚未标定。

## 复用与依据

- 世界场与目标双程衰减直接复用 `shared_weather_benchmark/world_field.py` 和 `ray_integrator.py`。
- B1 直接调用冻结的 `e0_adapter.py` 与 vendored Hahner hard/soft 内核；查表文件用原 `assets_lock.json` 校验。
- 新波形依据本地官方源码 `related_code/LiDAR_fog_sim/theory.py` 的
  `P_R_clear_hard`、`P_R_fog_hard`、`P_R_fog_soft` 和 `xsi`。
  没有导入其 GUI，也没有改写旧内核。
- 20ns 脉冲半宽、0.9–1.0m 线性重叠、gamma=1e-6 都来自该模型默认值，
  **没有证据将这些默认值称为 OPV2V 实际传感器参数**。
- beta/alpha=0.046/log(20) 对应 Hahner 默认 MOR 关系，额外假设空间中相函数比例不变。
  不表示知道了雾滴粒径分布；如果 alpha 用 m^-1，beta 对应 m^-1 sr^-1。

## 实际计算

对晴天已有返回点建立一条光路，目标回波强度乘以 exp(-2 tau(R))。
沿路在位置 s 计算 beta(s)、接收重叠、1/s² 和 exp(-2 tau(s))，再与有限宽 sin² 发射脉冲卷积。
用原始目标强度反推的相对峰值归一化，将散射与目标响应放在同一相对信号单位。
这一归一化依赖“原始强度与接收功率线性对应、目标反射率可用默认 gamma 代表”的未经校准假设。

具体软回波离散计算对应：

`I_clear * R² / (beta0 * overlap(R)) * integral(beta(s)*overlap(s)/s²*exp(-2*tau(s))*pulse(u-s)*2/c, ds)`

其中 beta0=gamma/pi。目标波形为 `I_clear*exp(-2*tau(R))*pulse(u-R)`。
对总波形取最强峰，报告距离扣除脉冲峰值时间偏移。
硬目标的精确峰位置额外加入候选，避免网格没有正好采到目标峰。

软回波需要前缀光学厚度，因此新增中点累计积分；终点衰减仍调用旧积分器。
两者差异必须低于既有 0.002 光学厚度数值门槛。
非均匀路径逐位置使用 alpha 和 beta，**从未以平均 alpha 查询均匀雾表**。
两条累计衰减相同、雾浓度前后分布相反的路径在测试中产生不同散射波形。

## 回波选择与来源

每条原始光路最多报告一个返回。原目标位置且硬分量占主导的峰保留原 XYZ；纯软峰输出散射距离；偏移的混合峰为 unknown。
“纯软”使用固定 1e-12 相对硬分量容差；目标原位置的硬分量占优规则是模型来源约定，不表示光子纯度。
偏移混合峰不被悄悄计入原始目标返回。报告保留上下界、硬/软分量及硬峰占优辅助指标；这些是模型条件下的统计，不能当作实测光子来源的保证。
GT 框只用于冻结 Clean 点的几何关联，绝不用于判断天气返回的来源。

相对强度按 1/255 量化，零编码或非正报告距离记为无返回。
**这是明确未校准的数字输出规则，不属于经过标定的硬件阈值，也不代表真实硬件对零强度点的行为。**
未引入随机丢点、训练式阈值或额外散射 RNG。零雾严格返回原始点，包括已存在的零强度点。
近场超出假设重叠范围时保留来源未知状态，不能声称已模拟其物理行为。

## 对照和平衡

B0=Clean；B1=原 Hahner；B2/B3/B4 都使用上述同一新引擎。
B2 为常数场；B3 共用场池；B4 对同一池按 CAV 身份循环错位。
场算法、mean=.06、length=25m、contrast=.8、modes=32 和20个场沿用 P7。
同一原始光路×同一个场只计算一次，B3/B4 重组完整波形选择结果。
检查逐车、逐固定光路的强度、距离、来源、无返回和 tau 分布身份。
没有额外散射随机性，完整循环边缘分布相同；单次重复不要求匹配。

B1 选择分开的 hard/soft 峰，包含原版取整、查表及 noise=10；B2 选择叠加波形，且来源规则不同。
二者不被宣称逐点等价。局部数学测试独立检查原 hard 解析衰减、锁定表的原 hard/soft 执行、
新均匀软响应与独立数值积分，以及积分/峰值收敛；服务器按 scene 输出 B1/B2 的实际差异。

## 严格对应和只能描述比较的量

R1_HAHNER_REGRESSION.json 保存40条预定合成光路的全部数值：

- 硬衰减在编码前为相同 exp(-2 alpha R)，原版 ADC 舍入逐项核对。
- 原版软查表、替换判定、零输出码和身份由锁定资源独立重放，noise=0 隔离方程。
- 新均匀软回波在相同时间坐标，与 Hahner 连续单次散射方程的独立时间积分比较。
- 新引擎波形非负，卷积面积等于离散分量面积之和；均匀与非均匀场检验步长收敛。
  面积单位为相对强度×米，没有焦耳/瓦特标定，不能据此宣布完整物理能量校验通过。
- B1 的生产设置仍用原 noise=10。LUT 峰值网格/时间约定、分开峰竞争和叠加峰竞争不同，
  最终距离、软峰、替换率、零输出码率只作描述比较，不要求逐点一致。

## 尚不能说明的部分

- 没有真实雾天数据读取、统计比较或校准，状态固定 NOT_VALIDATED_NO_REAL_REFERENCE。
- 不能恢复发射束、逐束时间、完整接收波形、遮挡后目标或晴天没有返回的射线。
- 原始强度是数字编码。真实接收阈值、噪声、强度功率曲线、脉冲及重叠函数均未标定。
- 零编码无返回只能说明数值输出规则；真实硬件丢失率尚无证据。
- 若出现混合峰，来源保留 unknown；模型“原始硬回波”标签不能作为实测光子来源保证。
- 原始零强度但存在的晴天点在零雾时原样返回；非零雾的零编码点记无返回，这个数字规则有零雾边界不连续性。
- 近场 overlap=0 时原强度无法反推接收功率，保留 unknown 并单独计数，不外推该区域。
- 未模拟多次散射。tau>1 比例必须报告；高光学厚度下数值有限不能证明单次散射可靠。
- strongest-total-peak 是明确的接收规则假设，未证明对应 OPV2V 实际传感器。

R0 缺真实参考不阻断 R1。数值、Hahner 回归和数据身份通过后，自动进入已获用户授权的
UNCALIBRATED_EXPLORATORY R2。检测差异只描述这套近似模型下的行为，不外推真实天气。
工程上已补上回波替换/距离变化/无返回路径；正式 SCOR-W 的真实物理可信度仍未建立。
