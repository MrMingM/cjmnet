# Radar 与 GSPR 候选质量实验

入口为 run_all.sh。默认海光物理卡 1 只负责一次共享候选提取。M1、M2、M3 为独立 CPU 进程。每组仅加载自己的评分头和同一份候选缓存。F0 权重取 R-A/R-B 实验 F0 正式第 20 轮并核实 SHA256。

共享缓存使用官方检测头解码、同帧主车坐标、原始 logit 和锚框 ID。去重前池完整保留原阈值以上候选，低分候选仅从前 128/256/512 中收集。收集下限比较 0.10、0.05、0.035、0.02。只用模型选择场景确定公共截取范围。训练场景每个等间距取 32 帧，两种天气读取相同帧。场景固定划分为拟合 22、选模 5、校准 5。验证使用三天气全量，每种 829 帧。雷达证据使用位置与空间统计。第四列原始运动编码的精确换算仍不明，本轮不读取第四列作为评分特征。

M1 比较无雷达质量评分、雷达条件评分、仅按各模态独立加分的对照、逻辑回归、点数及打乱对照。M2 宽松匹配头监督 0.3 重叠，定位头仅用宽松匹配样本监督 0.7 重叠，最终两者乘积和单头对照。M3 独立训练自己的基础和雷达模型，比较普通分类、随机候选对、同帧困难候选对，使用按训练场景划分的三个独立模型判断雷达增量方向。门控关闭时分别测回退到基础质量分数和回退到 F0 原始分数。没有严格概率置信保证。

评分和选择阈值锁定后，每种方法重新调用实际 OpenCOOD 后处理。F 使用固定 Clean 真值，O 跳过 None，O* 计入。正式 AP 沿用按帧累计。另报告全局排序 AP、训练场景固定误检预算阈值下的实际误检数和恢复数、验证场景块配对区间。较低分的正确候选按原始分数低于官方阈值及最终官方匹配定义。历史 LMD、SAQC 和 CIA-SSD 风格实验使用不同数据与冻结检测器。此处的分数阈值基线、线性逻辑回归、点数和单头质量评分均在同池重测。

运行目录默认 /data/cjm/datasets/logs/v2xr-griq-experiments-v1。候选按帧提交，完成组按哈希复用。每组训练结束提交 best.pt，校准完成后锁定 CALIBRATION.json，评测按天气提交。未提交的训练阶段可从固定种子重跑。最终 COMPLETE.json 只在三组均完成后写入。
