# E2固定权重目标网格诊断

独立源码目录，不修改gspr_e1e2_v5或旧实验。仅加载selected.json指定的E2最佳权重，核对20轮完成记录、选模合同和SHA。无训练入口，无优化器。

四个模式：on全部增强；off全部关闭；observed_only仅增强原本有点目标网格（关闭空网格）；empty_only仅增强原本空目标网格（关闭有点网格）。来源始终是增强之前有实际观测的网格。以同一帧首次前向的Scatter输入、增强输出和原始占据掩码回放各开关，避免重复前缀计算的微小差异。

默认Clean/Fog/Snow各829帧，复用官方后处理、AP匹配与O/O*/F协议。O在预测为None时跳过该帧；O*保留该帧官方GT；F固定Clean GT。逐目标召回和定位使用F、IoU0.7。

距离分组0—30、30—60、60+米；目标点数0、1—5、6—20、21+，后者是各车原始天气点云落框点数之和，与柱体点数不同。近距离密集组预定义为距离<30米且至少21点，结果包含全部距离×点数交叉分组。不存在使用目标GT来决定传播的操作，GT仅用于事后评分。

输出RESULTS.json/md：三协议AP、TP/FP/FN、on−off及off−E0差值、Snow交叉分层、各模式原有点/空网格非零修正数与RMS、恢复/丢失目标ID和共同匹配IoU差。

on−off是给定E2训练权重时C的推理贡献；off−E0含整个非C路径的训练差异，包括GSPR、柱内聚合、主干、融合及检测头。单种子且选中轮次可能不同，不据此声称纯主干因果效应。部分开关经后续网络可能存在非线性交互。

唯一入口run_all.sh，默认GPU=6、MODE=all，先跑每天气0/828两帧smoke并执行GPU张量掩码精确检查，再跑全量。MODE=smoke仅验收。两种模式分目录，不能混作正式结果。预先拒绝占用中的GPU；不停止其他任务。

逐帧四模式预测作为一个原子记录保存，自带合同、输入、载荷哈希；恢复时重建完整评价统计，已完整保存的帧跳过模型推理。中断时最多重跑当前未提交帧的四次前向，无逐批训练恢复问题。权重及BN状态前后精确检查。变更代码、权重、输入或合同将拒绝旧缓存；需要独立新输出目录。

本机仅编写和静态检查，没有运行任何Torch/科研实验；服务器验收尚待操作者执行。未产生新AP成绩。长任务使用后台命令：

```sh
nohup env GPU=6 MODE=all sh /home/cjm/OpenCOOD-main/cjmnet/gspr_e2_grid_diagnostic/run_all.sh > /home/cjm/datasets/logs/e2_grid_diagnostic_v1.launch.log 2>&1 < /dev/null &
```

输出/home/cjm/datasets/logs/e2-grid-diagnostic-v1；小验收输出同路径加_smoke。重新运行同一入口自动续用完整帧缓存；仅在旧进程退出后恢复，建议日志重定向使用>>以保留历史。
