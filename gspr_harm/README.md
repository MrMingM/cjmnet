本轮有六个分支：A0B0、旧 ΔL 联合删除、新候选联合删除、三次匹配新候选发送量的随机删除。新候选从所有已测区域中选取，不限定 ΔL 类别。条件与机会检查完全相同：单独删除时不丢任何原匹配，并且恢复目标且不增加误检，或者不改变匹配但减少误检。这里的匹配按 IoU0.7，条件不是直接用 AP 打分。

## 区域、损失和判定

默认一个已有通信块为一个区域，物理边长为 `(8*voxel_x, 8*voxel_y)` 米。例如 voxel=0.4 米时为 3.2×3.2 米，接近车体横向尺度；`--region-blocks 2` 对应 6.4×6.4 米，可作为考虑目标长度及上下文的独立粒度实验。实际尺寸写入 audit.json，不能假设所有配置都是 0.4 米。

粗区域只删除其内部已发送的原生块，不添加未发送区域。区域可能包含未发送空洞，记录具体 native block 坐标，避免把整片区域误认为全已发送。未采用逐 BEV 像素穷举。

对每个候选区域，计算 `ΔL = L(原始 A0B0 消息) - L(仅删除该邻车区域)`。

- ΔL > ε：在当前其他消息全部固定的背景下有害。
- ΔL < -ε：在该背景下有益。
- 其余近中性；不能把浮点小差异直接判成有害。

两支使用同一份完整检测损失和 GT。当前损失的分类为 focal（alpha=.25、gamma=2），回归为带角度正弦编码的 SmoothL1（beta=1/9）；均按每帧正 anchor 数 clamp(min=1) 归一化，再按 batch 平均。**原实现将 pos_equal_one==0 当负样本，没有使用 neg_equal_one 屏蔽忽略区**，本实验如实复用并在此说明，不偷偷更改训练目标。

第一版不裁局部损失，所以区域外的连带影响仍被计入；代价是很小的区域效应可能被完整损失的数值精度掩盖。记录分类和回归差、重复数值漂移及每帧正 anchor 数，便于识别此限制。未发现大于 ε 的效应，不等于绝对不存在效应。

每种天气先在独立于被统计帧的 2 个训练帧中，原样重复接收侧前向 3 次。固定 ε = max(绝对下限 1e-6，校准损失中位数×1e-5，最大重复分量漂移×10)。这是预设的数值诊断阈值，不是经过性能调优的“有害程度最优阈值”。正式帧也检查重复漂移，超过校准界限即停止，不自动放宽阈值继续解释。

## 联合检验与结果

| 输出对照 | 意义 |
|---|---|
| `a0b0` | 原消息全部保留。 |
| `gt_single_deletion_joint` | 将单区域 ΔL>ε 的区域一起删除，实际重跑融合和检测。GT 辅助诊断，不是可部署过滤器，也不是严格最优 oracle。 |
| `random_0/1/2` | 每帧、每邻车删除相同原生块数，匹配实际字节，随机选位置。对粗粒度实验，随机对照匹配原生块数量，不承诺连通形状相同。 |

所有对照保留原请求和响应头，空响应也保留头部；减少的是实际删掉的三尺度块与索引，没有重新分配预算。联合与随机实际序列化长度均检查，统计的是应用层字节，不包含无线链路开销。

`summary.json` 是主要回传文件，含各天气有害/有益/近中性比例、出现有害消息的帧数、联合及随机的 AP50/AP70、平均损失、平均字节、相对 A0B0 的恢复/丢失目标数和 FP 变化。目标计数使用 IoU0.7。随机结果分别保留，8 帧小样本不能支持稳定性或泛化结论。

`regions.jsonl` 保存逐区域成对损失、分类/回归差、区域坐标、车辆 ID、恢复/丢失目标数；`frames.jsonl` 保存每个联合/随机对照的实际删除集合、损失、字节。每帧目录保存原始实际 wire packets、请求、GT 标签、可重建输入的数据索引/路径、天气种子和输入/标签哈希。重新预处理时须验证输入哈希；不是仅靠种子声称重建逐位一致。此处没有保存或训练预测头输入。

结果应这样判断：

1. 单区域有害比例明显且联合删除优于 A0B0、优于等量随机：才说明有针对性过滤值得继续投入；仍需更大场景验证。
2. 存在单区域损失收益，但联合 AP 没有改善：检查区域相互作用、损失与 AP 不一致，不能直接进入预测头训练并保证收益。
3. 联合与随机差不多：收益可能主要来自减少消息，而非识别有害区域。
4. 有害区域极少、影响极弱：当前 A0B0 下过滤的提升空间可能有限，不把低 AP 自动归因于“有害消息太多”。

后续是否能用邻车本地特征预测这些效果，是另一项可学习性验证。本实验只提供固定背景下的真实成对结果，不承诺本地输入能精确恢复每个样本的效果。
