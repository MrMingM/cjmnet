# 旧B1实现审计

审查gspr_repe/models.py、modules.py及原GSPR接入与官方PFN源码，以下属于直接代码证据。

1. B1的_before_pfn在A启用时不调用原GSPR的PFN前乘r钩子，直接对未乘可靠性的装饰特征执行原linear。随后Aggregation的value也来自这份装饰特征，可靠性只进入其打分先验。因此不能把B1理解为完整保留B0后只增加聚合。
2. B1只对有效点执行BN，原版对所有槽位执行BN。它还将pfn.forward替换为返回预先算好的masked max；填充点从BN和Max中排除。可靠性、归一化和池化同时变化，构成混淆。
3. Aggregation使用一个全局可学习标量sigmoid(g)混合h_max和h_weighted，初始g=-5。用户报告训练后新分支约2.41%，本轮尚未直接读取该旧权重验证该值；不将其作为本轮实测。小混合系数也不能证明归一化等改动很小。
4. 用户报告Fog/Snow下降；本次不补造旧B1的AP或唯一根因，需结合原实际结果分析。

新实现保留原GSPR加权、官方PFN完整前向和BN更新方式。残差来自同一次PFN中间输出，采用逐柱强度，没有全局混合参数。

无需完整重训的诊断：server_tests在真实数据读取后，固定同一批装饰特征、PFN权重及初始BN状态，对原可靠性加权开/关、原/有效点BN、原/掩码Max做2×2×2八组探针，逐项报告柱特征与BN统计差异。最多取首2048柱，使用独立复制的层；不更新A0模型，不把探针差异称作AP因果效应。GGCA的额外结构测试另核对关闭/零残差的整模型输出和BN状态。
