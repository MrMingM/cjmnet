# 候选级检测可靠性的研究空白：方法组合与验证标准

> 历史文献检索材料。部分提案已有后续服务器失败结果；当前待验证方案以 [有效方向清单](01_active_directions.md) 为准。原文保留用于文献追溯。

## 核心判断

较可信的空白不在于“再做一个 IoU 质量头”或“把排序损失迁移到另一种数据集”，而在于**推理时可观测证据 × 可靠性目标 × 候选竞争方式 × 恶劣天气协同域偏移**的交叉组合。现有工作已经覆盖 IoU/质量估计、质量感知分数重排、成对与列表排序、3D 后校准和协同天气特征去噪等相邻部件；因此，下述方向只是可辩护的待验证问题，不能据此宣称新颖。

此判断基于前轮识别的代表性论文摘要/来源摘要，而非逐篇核对全文或穷尽式检索。特别是具体输入张量、损失公式、数据划分和附加前向次数在不少摘要中未报告；所以“未见到该组合”代表现有证据集不足以确认覆盖，不等于全领域不存在先例。

## 相邻方法已经覆盖到哪里

| 方法簇 | 已覆盖内容 | 仍未由这些摘要确立的内容 |
|---|---|---|
| 绝对 IoU / 定位质量预测 | IoU-Net 预测检测框与 GT 的 IoU，并以预测 IoU 改善 NMS 保留与框细化；SAQC 从目标中心附近的局部 BEV 特征估计定位质量，与原始分数融合，再作 sigmoid 校准。[^1][^2] | 这些描述本身没有证明预测值在恶劣天气、协同感知域偏移下仍校准；也没有说明使用分类—回归内部一致性或竞争者关系是否带来额外价值。 |
| 排序及候选竞争 | Learning to Rank Proposals 以 IoU 监督候选 NMS 排序，并采用难样本对；Rank & Sort 对正负样本排序并按定位质量排序正样本；YOLO-AlignRank 结合候选集合内列表分布对齐和成对 hinge 排序。[^3][^4][^5] | 这些结果使“成对/列表排序本身”或“难负例排序本身”不构成稳妥的空白。仍需核验它们是否专门把竞争限定为同一局部重叠/NMS 冲突集合，以及是否跨天气/协同数据验证。 |
| 3D 校准与域偏移 | 条件式 3D 点云校准考虑位置和尺寸引起的置信度偏差；Query2Uncertainty 将 DETR 查询特征密度与后校准结合，在分布偏移下联合校准分类与框回归不确定性。[^6][^7] | 现有描述支持“校准与域偏移已有人研究”，因此只更换天气数据集不是方法空白。其与候选级 IoU 超阈值概率、低分高质量框晋升、局部 NMS 竞争或协同多智能体证据的组合是否已实现，需查全文和近邻工作。 |
| 协同恶劣天气 | Co-Denoising 对各智能体特征作采样式去噪，并在协同阶段以贝叶斯神经网络扩展全局特征，目标是降低雨天等噪声造成的协同性能下降。[^8] | 已见摘要针对特征/协同表示的噪声鲁棒性，并未描述候选级质量目标、检测分数校正或 NMS 竞争级可靠性。该边界是摘要层面的，不是对完整协同感知文献的否定。 |
| LiDAR 质量分数的解释 | LiDAR 3D IoU 分数研究指出预测定位分数不必然有充分依据可解释为置信度，并认为几何特征与训练目标分布会影响估计和排序。[^9] | 不能只报告 AP 提升或 IoU 回归误差；需要分别验证绝对校准、跨质量区间排序以及决策后果。 |

## 值得验证的组合型空白

### 1. 同一候选的分类—回归内部一致性 → 分数残差或质量区间概率

**待验证组合：** 在单个候选内联合使用分类 logit、回归分布/参数、解码框几何及二者的内部一致性，估计“真实 IoU 超过指定阈值的概率”或相对于原始检测分数的残差；以残差校正原分数，而非仅额外训练一个绝对 IoU 回归头。

**最近邻覆盖：** IoU-Net 建立绝对 IoU 估计并用于 NMS；CLQ 通过轻量 LQE 分支并与分类分支联合训练；SAQC 则从局部 BEV 空间特征估计质量并融合原分数。[^1][^10][^2]这些方法表明“附加质量估计并修改检测排序”并非空白。

**剩余差异：** 可检验的问题是，显式比较同一框的分类证据与回归/几何证据，是否比质量头单独回归 IoU 更能识别“高分类分、低定位质量”与“低分类分、高定位质量”，尤其是在天气变化下。目标也可从连续 IoU 扩展为多个 IoU 阈值上的校准概率或 score residual，但这只是候选定义，需先查全文确认先例。

**空白性质与先例风险：** 若仅把 CLQ/LQE 或 SAQC 应用到协同 LiDAR 数据，主要是应用迁移，方法空白弱；若能证明显式的同候选一致性特征与残差/阈值概率目标提供了独立、可重复的增益，才可能是方法学差异。**先例风险：中高**，因为质量分支、分类联合训练、质量分数融合及 3D 后校准均已有近邻。

**证明意义所需证据：** 在完全相同候选池上做消融：原始分类分、IoU 头、回归分布/几何、显式一致性、残差校正、阈值概率分别比较；报告校准误差、可靠性图、各 IoU 阈值下的排序指标、低分高质量候选的晋升率和高分低质量候选的抑制率，并按天气、距离、点数/稀疏度分层。训练监督必须明确只在训练阶段使用 GT，推理阶段不得泄漏 GT。

### 2. 仅在局部重叠/NMS 冲突集合内建模候选竞争

**待验证组合：** 使用候选框及其局部重叠邻居、原始分类分和回归/几何证据，预测相对排序或 NMS 冲突内的胜出概率；只调整发生竞争的候选，不对全体分数作无差别全局校准。训练可比较 pairwise/listwise 排序、难负例及 NMS 竞争目标。

**最近邻覆盖：** IoU-Net 将预测 IoU 用于 NMS；Learning to Rank Proposals 学习 NMS 抑制排序并使用难样本对；Rank & Sort 与 YOLO-AlignRank 已覆盖正负样本排序、正样本质量排序，以及成对和列表式对齐。[^1][^3][^4][^5]

**剩余差异：** 关键不是“候选之间排序”——已有明确先例，而是排序作用域是否被定义为局部重叠竞争图、目标是否直接对应 NMS 决策冲突，以及该机制是否能挽回原始分数低但质量高的候选，同时避免把不同真实目标的重叠框错误压制。还需区分同一物体重复框与相邻真实物体的竞争。

**空白性质与先例风险：** 泛化的 pairwise/listwise ranker 属已有方法家族；把它称作新颖会有高风险。局部冲突集合的明确建模、以 NMS 决策结果为目标、及对低分高质量/高分低质量反转的定量审计，若现有全文确未覆盖，才可能形成较窄的方法学差异。**先例风险：高**。

**证明意义所需证据：** 与标准 NMS、Soft-NMS/已有学习型 NMS、全局质量分数重排及全局 pairwise/listwise 排序作同候选池比较；按冲突集合大小、重叠强度、类别、天气分层；报告 AP 外，还应报告 NMS 保留决策的准确性、冲突对排序一致性、低置信高质量框的召回变化，以及对不同真实目标误抑制的代价。

### 3. 恶劣天气域偏移下的候选级质量概率，而非仅分数校准

**待验证组合：** 针对雨/雾/雪及传感器退化，利用候选特征、回归/几何与局部点云证据，估计条件化的 IoU 阈值概率或有序质量；在推理时依天气/域线索校正排序或 residual，并明确检验域外校准，而非只在总体验证集上作单一后校准。

**最近邻覆盖：** Query2Uncertainty 已将潜在查询特征密度用于分布偏移下的分类与框回归不确定性校准；条件式 LiDAR 置信校准已考察位置/尺寸因素；SAQC 直接针对 BEV LiDAR 的 score–localization 关系。[^7][^6][^2]

**剩余差异：** 由此，单纯“恶劣天气下做置信度校准”可能只是把已有 3D 域偏移校准移到新天气集。较具体的问题是，域条件化校准是否能维持候选之间的定位质量排序，尤其改善低分高质量框和高分低质量框的反转；同时区分天气造成的输入域变化与协同融合造成的表示变化。

**空白性质与先例风险：** 若仅比较晴天与雨天 AP，是应用研究；若评价在目标天气数据稀少或无标签时的候选级阈值概率、排序稳定性和校准迁移，并以天气/传感器退化机制作分层，方法问题更实质。**先例风险：中高**，因为域偏移不确定性校准已有相邻方法，需查它是否已含候选质量/排序输出。

**证明意义所需证据：** 训练天气与测试天气严格分离，报告 ID 与 OOD 下的阈值概率校准、排序相关性、各质量段误差与检测效用；比较不校准、温度/后校准、SAQC 式质量融合、密度条件化及组合方案。还应做跨传感器退化和雨/雾/雪迁移，控制候选池与框几何不变，避免 AP 变化仅由框生成差异造成。

### 4. 协同感知新增的跨智能体可靠性证据 → 候选级质量与竞争决策

**待验证组合：** 对同一物理目标的多智能体候选建立跨视角/跨智能体对应关系，利用各自候选的分类—回归一致性、定位估计分歧、可见性/天气条件和几何一致性，预测候选级质量或候选胜出概率；比较该信息对单智能体质量估计的增量价值。

**最近邻覆盖：** Co-Denoising 在协同阶段对全局特征使用贝叶斯神经网络并在各智能体作采样去噪，关注的是天气噪声与特征不确定性；现有直接 LiDAR 校准/质量评分近邻包括 SAQC、LMD 和 Query2Uncertainty。[^8][^2][^11][^7]

**剩余差异：** 合作感知在概念上提供单传感器没有的证据——另一个智能体对同一目标的独立观测、定位一致性/分歧及各自天气退化程度；但 Co-Denoising 的特征级不确定性并不等同于候选级定位可靠性，也不证明多智能体信号能改善候选排序。是否存在可靠的跨智能体候选匹配、时延/位姿误差下的信号可用性，仍是需要实测的问题。

**空白性质与先例风险：** 将单车校准直接放到协同数据集属应用迁移，空白有限；利用明确的跨智能体候选对应/分歧信号，证明其在控制单车候选质量、几何和通信条件后仍提供增量预测能力，可能构成更实质的组合问题。**先例风险：中等且不确定**：已识别的协同天气摘要偏特征去噪，但当前检索不足以排除其他候选级协同校准工作。

**证明意义所需证据：** 需要同一候选池下的单车、融合特征、跨智能体候选一致性/分歧逐项消融；按通信延迟、丢包、位姿误差、可见范围及天气强度分层；对齐同一目标并防止错误匹配泄漏；评估可靠性校准、竞争决策、低分高质量候选召回和总体检测效用。应做移除一个智能体、单智能体伪协同等负对照，说明增益来自协同证据而非额外算力或更多点云。

## 四个维度的覆盖判断

以下“值得核验”组合是基于所检查摘要的比较性研究假设和验证建议，不是已由这些论文实验证明的结论；它们需要通过全文核查及实验检验。

- **A. 预测目标：** 绝对 IoU、质量分数、IoU 导向排序、成对和列表式排序、NMS 抑制排序均已有明显先例。作为下一步核查问题，可比较候选级 IoU 超阈值概率/有序质量或 score residual 与局部冲突排序、域条件化可靠性是否已被联合采用；仅改变目标形式不足以证明方法新颖。[^1][^3][^5][^7]
- **B. 推理证据：** 局部 BEV 特征、检测器预测分数、潜在 object query 和框几何相关信息已有不同形式的邻近研究。明确使用同候选分类—回归一致性、竞争邻域及跨智能体同目标分歧的统一证据组合，在已检查摘要中未被明确描述；这是待全文核对的证据缺口，不是已证实的文献空白。[^2][^9][^7][^8]
- **C. 对检测决策的作用：** 替换原生 objectness（LMD）、质量与原分数融合（SAQC）、以及排序后影响 NMS 的 IoU-Net/学习型 NMS 都已有先例。作为待检验设计，可比较仅对冲突候选校正，与全局重排是否不同；若研究目标是挽回低分高质量框、抑制高分低质量框，应预先量化这两种错误的变化，不能把一般 reranking 重新包装成新方法。[^11][^2][^1][^3]
- **D. 训练目标：** IoU 回归、质量加权/排序、成对难例、列表对齐及混合分类—排序均有近邻。可进一步核查这些监督是否已与域条件化阈值可靠性或显式 NMS 冲突决策形成联合目标，并在天气/协同迁移中与分解式训练作对照；这项建议本身不构成现有论文已验证的结论。[^10][^3][^4][^5]

## 结论与下一步文献核查

最稳妥的研究定位是：**检验额外推理证据能否在固定候选池上改善定位质量排序及决策，而非宣称首次提出 IoU 估计或排序。** 优先核查两个组合：（1）同候选分类—回归/几何内部一致性对质量残差或 IoU 阈值概率的增量；（2）协同天气条件下，跨智能体候选一致性/分歧是否比单车质量估计带来独立增益。局部 NMS 冲突排序的先例风险最高，应首先与学习型 NMS、Rank & Sort、YOLO-AlignRank 等全文方法比较。[^3][^4][^5][^8]

目前能改变空白判断的关键证据，是对这些近邻论文全文进行系统核对，尤其确认其真实推理输入、目标定义、校准/排序损失、NMS 作用范围，以及是否已经在协同天气域偏移下联合使用跨智能体候选证据。若发现有工作已覆盖这些组合，研究贡献应转向严谨的域外评估、可靠性失效分析或特定任务下的实证验证，而不是继续主张方法新颖性。
