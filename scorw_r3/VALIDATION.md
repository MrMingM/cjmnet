# 交付验收范围（argsfix）

上版仅执行合成数值、静态及假检测器/编解码器单元测试。本次argsfix只执行静态检查，不在本地执行科研数值实验、OPV2V或AttFuse推理；服务器实验由用户启动。

历史v1测试结果：Python3.11.7，原34项全部通过，0失败、0错误，用时12.987秒。历史日志保存于不提交的 `local_validation/UNIT_TESTS.json`。本次新增8项空参数列表、异常格式、科学参数不变、缓存只读采用/身份变化拒绝及新合同恢复验收；服务器smoke/full的numerical阶段自动重新执行全部42项。新增测试尚未在本地或服务器执行。静态检查包含Python3.10语法、JSON、LF及旧冻结源码哈希。

验收覆盖：

- Hahner 40条合成回归：硬衰减、LUT重放、新软波形独立积分、面积恒等式和步长收敛。
- 正强度线性与选峰不变性；零强度、零雾和近场分支；数字零编码重放；单因素敏感性不修改正式配置。
- 20场唯一身份、跨scene隔离、2/3/20CAV偏移、超20CAV拒绝、逐车完整边缘平衡及共同移位负对照。
- future/历史排除、仅原train访问、天气计算前完整预算、全局排序AP与scene AP均值的区别、空预测和空GT。
- Neighbour类别以预测定义、Ego输入输出身份、预测缓存只计算一次、合成完整20场缓存→三范围预测→分析及恢复。
- 整scene统计单位、场景不足不虚增置信度、AP和目标事件共同满足小效应门槛才建议统计停止。
- 原子事务、中断恢复、改变合同/修改提交后拒绝、失败后不发布旧正结论、历史根层报告中途变化拒绝。
- Python3.10语法、JSON解析、LF换行及shell禁用结构扫描；87个原R0–R2源文件逐字节SHA256不变。

测试命令：`python -B -m unittest scorw_r3.tests.test_r3 scorw_r3.tests.test_argsfix -v`。服务器smoke/full自动先执行同一套测试。小型合成流程中的假检测器结果只用于验证程序组合，不支持任何检测效果结论。

Windows Git sh 在当前沙盒无法完成原生解析，因此没有声称本地Linux shell验收通过。脚本只使用POSIX结构，每次服务器启动先执行 `sh -n "$0"`，语法失败立即停止。

数值验收通过不证明物理真实性。真实雾天标定、OPV2V接收阈值/强度功率映射，以及新scene实际检测结果仍待服务器与未来真实参考数据验证。
