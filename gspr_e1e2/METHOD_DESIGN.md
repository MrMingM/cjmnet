# E0/E1/E2 方法及冻结实验协议

E0复用原GGCA A1（/home/cjm/datasets/logs/gspr-ggca-v3/A1）的Clean选模权重及完整三天气结果。E0无训练入口。E1/E2从该A1的完整第0轮状态对齐全部192个共享模型张量；E2的C只取旧B2第0轮额外张量。核对两份初始状态的共享主干/GSPR相同。禁止用任何训练后的最佳权重作新训练初始化。

## E1：点级可信自身保留 S

原A1点特征f来自同一次官方PFN的BN/ReLU，已经受到原GSPR可靠性加权。原PFN Linear/BN/ReLU/Max保持；只在A1原邻居消息m之后插入一次点级混合。

原A1最多4个有效非自身邻居，关系权重a完全保留。令p=r(1-u)，q=sum(a*p_neighbor)，e=sum(valid_neighbor*p_neighbor)/K，K=min(4,槽位数)。q描述权重下的邻居可信度，e描述当前邻域的绝对可信观测量（最多4份单位证据）。

alpha = 0.5*p*sigmoid(b + softplus(w0)*(p-q) + softplus(w1)*(1-e) - softplus(w2)*u)

m_new = alpha*f + (1-alpha)*m_A1

共4个参数：b及三个正向幅度。初值b=-1.5，softplus(w)=[2,1,1]，不消耗随机数。当前点可信、邻居较差或可信观测少时提高自身保留；邻居更可信时允许原A1消息继续参与。alpha上限0.5*p，因此邻居消息始终至少保留一半；不硬删点、不造点、不乘原柱体残差门。无有效邻居时A1本来已取自身，alpha记0，明确为无需交换，不是噪声标签。保留A1原可靠性池化、逐柱残差门和零初始化输出投影，无新辅助损失，无A2几何共识。

初始示例：p=.9/u=.1、邻居p=.1时alpha约.32；邻居p=.9且邻居齐全时约.082。低可信自身不会被同等保护。数值是公式示例，非实验成绩。

实现通过解析冻结A1源码，在唯一消息赋值后插入mix_self；其余原函数保持原AST。关闭S直接执行原A1函数；alpha=0的行为另做严格非零A1残差测试，防止零初始化掩盖差异。

## E2：A1加普通八邻域 C

直接实例化gspr_repe/modules.py的Enhancement类，constrained=False，state_gate=False。无Observation、旧B1聚合、质量来源权重、候选目标门或辅助监督。

Scatter后构建occupied，仅取真实体素坐标及voxel_num_points>0。每车单独进行8邻域传播，来源只允许occupied。key/value、exp(cosine)/(1+dx²+dy²)、归一化及sigmoid残差门均为旧B2原代码。目标网格不乘occupied，故允许把特征传入原本空网格。补零切片无环绕、不跨CAV。C初始gate.bias=-5与旧B2一致；关闭C或将其修正强制为0严格恢复原A1行为。

## 共同配方与解释范围

V2X-R 8083训练协作帧；20轮，batch8，seed20261017，Adam lr=.002/eps=1e-10/weight_decay=1e-4，官方[10,15] gamma=.1调度及零起始epoch调用语义。每车独立Clean4/7/Fog3/7，Snow不参与。数据包装器、损失、逐轮提交、初始RNG与官方O/O*/F推理评测均复用旧引擎。每轮完整829帧Clean O AP70选模，同分选早轮；完成20轮后才锁定三天气权重。只访问validation，不访问test。不同模型不能以Snow结果调整门控参数。

完整状态恢复包含模型、Adam、调度器、损失累计、Python/NumPy/Torch CPU/设备随机状态。只承诺完整轮次恢复，未提交轮次可重跑。源码/配置/数据/已完成阶段哈希不匹配即停止，不修改历史标记。

恢复单元测试另外在严格确定性条件下检查完整模型和Adam的下一步逐位一致；仅将无梯度、无模型输入用途的诊断直方图在CPU统计，以满足HIP确定性接口。正式训练保留原A1的非确定性设置。实际预先对照发现原A1/E1/E2默认下一步最大位差约4.38e-8/7.82e-8/5.77e-8，三者保存状态恢复均精确；确定性测试中三者下一步差值均0。证据保留在早期v4/resume_investigation/，不据此修改正式训练或放宽关闭/零修正等价检查。

E1−E0测量S的新增贡献；E2−E0测量在A1上增加普通C的贡献。另报告旧B2结果和对应初始化/配方身份，不把跨训练权重的分数变化当作推理开关因果效应。

## 预先固定的机制诊断

24个均匀索引[0,36,...,828]×三天气。E1在同一选模权重、同一缓存GSPR/PFN前缀上比较adaptive、uniform、shuffled、off。uniform匹配有邻居有效点的平均alpha；shuffled按柱体点数分组对有效点alpha作一次固定种子置换。记录逐点/逐柱门控分布、原残差系数及实际修正RMS；不比较不同输入前向的微小HIP数值漂移。

E2在同一权重上比较C on/off，统计已有点/空网格的接受数、修正强度、来源质量规则（真实观测掩码），不添加新来源门。

完整829帧正式匹配记录计算正确检测/误检/漏检、距离0–30/30–60/60+米、目标原始点数0/1–5/6–20/21+召回，并保留恢复/丢失ID。目标点数是各协作车原始天气点云落框点数之和，不是截断到32槽的柱体点数；两者分开统计。重点报告Snow目标1–5点召回。诊断不调参、不改选模规则，单种子不作显著性或机制成立保证。

## 执行顺序

唯一run_all.sh：共同全量预检/E0复用审计 → 服务器结构测试 → E1/E2在两张空卡并行各2步真实小训练及三天气12帧推理 → 两组共同验收 → 两条独立正式训练/评测/机制诊断通道并行 → 最终汇总。MODE=smoke默认只验收；MODE=all在验收通过后正式运行。一个通道失败会停止本次另一通道的活动子进程，保留所有完整轮次状态后退出；不停止其他任务。

小训练之后还在每种天气固定索引0/828上执行同权重开关验收，E1四种开关、E2两种开关；参数/BN保持检查、目标点数和柱体点数分开统计。不将这份两帧小验收作为正式机制结果。
