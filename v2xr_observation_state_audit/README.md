# 冻结 F0 观测状态诊断

在海光用 `sh run_all.sh smoke` 进行真实帧联调，用 `sh run_all.sh full` 自动完成冒烟和全量。输出路径可通过 OBS_OUT 指定，GPU 默认物理卡 4。每种天气使用相同的固定网格采样和当前帧主车观测，特征取主车双传感器、拼接、第一层共享主干和该层 AttFuse 输出。原始柱的占用位单独保存，无柱采样对应零填充。主干及融合特征含邻域信息。

A 与 C 是近水平射线的局部证据，穿越和受阻由端点距离、方向及独立角度数判定。无法判断的区域记 Unknown，整柱可见性或真实遮挡没有独立标注。B 用天气点云与配对 Clean 中对应位置的点数判断完整丢失，至少 3 个 Clean 点才标注；天气新增杂波可能掩盖丢失。D 仅根据同一局部窗口内两种传感器回波。B 可与 D 共存。标签使用主车，因此不推断每辆邻车的可见性。

固定目标分析只在离线已知位置取样，使用固定窗口，不能在部署时直接访问漏检目标的真值位置。预测框只使用原模型输出。Clean 信息仅进入单列的 Oracle 对照和 B 标签。训练和测试按场景留出，跨天气测试同样排除测试场景，避免相同路段同一时间戳进入训练。

输出包括每帧压缩缓存、D2-1.json、D2-2.json、FINAL_REPORT.md 和可核验哈希。
