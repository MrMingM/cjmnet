# R-A / R-B 双模态消融

原始 LiDAR → 冻结实现 GSPR → 原 PFN 和 A1 → 原 64 通道铺图。
原始 Radar → 原 PFN → R-A → 原 64 通道铺图。
R-B 在同车同格的原始雷达柱位置修改拼接张量中的 LiDAR 半边。
之后继续使用官方 128 通道 AttFuse 主干、检测头、去重和 O/O*/F 评测。

R-A 只搜索同车非空柱，默认半径 1.2 米，最多 8 邻居。根据三维位置、距离、点数、离散度和特征关系聚合。有界残差初值为零，孤立柱保留原值。原始稀疏坐标定义有效雷达掩码，支持度由局部点数和距离加权邻居数形成。

R-B 在原始雷达掩码内计算，以独立 LiDAR 占用标记和未知哨兵 -1 区分缺测与低可靠性。条件输入包括双路特征、点数、离散度、可靠性、不确定性和雷达支持度。投影初值为零。支持度限制残差上界。普通对照使用同样大小的网络，仅用传感器特征进行门控，不读观察统计。

F3 只在训练访问另一种天气的同车同帧点云。原生路径同步投影、范围、视野和分柱，恢复额外读入前的随机数。输入标签不进入模型。软标签由 75% 点数损失及 25% 空间离散度损失组成，Clean 有点而 Fog 全空为 1。Clean 无点不监督天气损失。只对采样到 Fog 且真实有雷达柱的已知区域做辅助损失，用原始雷达支持度加权。另约束可靠性至少 0.7 的健康格子的残差。权重为 0.1 和 0.05，可在配置中设零。未读框标注构造标签，未要求恢复逐值 Clean 特征。两路点数与离散度使用原生每柱最多 32 点后的样本，饱和柱的损失可能被低估。

F0/LR1、F1/R-A、F2/R-A＋R-B、F3/F2＋配对、F2-ordinary/等参数普通残差依次独立从零训练。20 轮、批 8，沿用 LR0 每车抽样、优化、验证和保存。海光历史 LR1 目录首次查无正式结果，因此新目录补跑 F0。逐帧核验 F 的 6,235 个固定目标。正式三天气后运行 F3 的关雷达、同车柱点位置打乱和模块开关。打乱保留占用集合，移动整柱点到同车的另一个已占位置。目标诊断以固定 Clean 框内实际投影点计数，记录相同目标恢复、丢失和共同匹配的重叠变化。未匹配预测单列，避免强行分给某个真值组。
