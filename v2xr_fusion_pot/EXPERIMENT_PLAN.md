# POT-CF 对照实验计划

| 组别 | 训练和融合 |
|---|---|
| P0 | 复用已核验的正式 LR0，原同位置注意力。另用同一权重在 GPU 4 复测速度与精度 |
| P1 | 从零训练，3 × 3 普通跨车注意力与匹配残差 |
| P2 | 从零训练，同一窗口、参数和候选，换成非平衡最优传输 |
| P3 | 从零训练，P2 加独立观测路径 |

P1、P2、P3 的共享权重和数据随机状态从与 LR0 相同的种子构造。P1、P2 的新增参数量一致。P3 增加独立路径的投影和门控。验收中的两步真实更新和四步冻结主干原型均从 LR0 第 18 轮权重出发，只用于检查模型、数值、数据、梯度和恢复状态。

## 正式协议

- 同一 V2X-R 训练集共 8,083 帧，每车按 Clean 4/7、Fog 3/7 抽样，雷达为原始同帧输入。
- 批大小 8，种子 20261017，Adam 初始学习率 0.002，沿用 LR0 的 10/15 调度与 20 轮，每轮 1,010 次更新。
- 完整 Clean 验证集按 O AP70 选轮次，同分选早轮。Clean、Fog、Snow 分别评测 829 帧。
- AP30、AP50、AP70 是检测框分别在三个重叠阈值下的平均精度。O 用当天气真值且略过无预测返回帧，O* 用当天气真值并把这些帧算作零预测，F 始终用 6,235 个双模态 Clean 目标。F 严格核对逐帧对象身份和框哈希。

## 干预和机制分析

P3 固定权重，分别关闭匹配、关闭未匹配、关闭整个模块，或改变窗口和传输正则项。关闭雷达时仅清空进入模型的雷达柱体，评分真值保持一致。实际空模态在验收与正式过程中单独记录。P2 固定权重进行拒配槽推理对照。

按天气、距离、传感器来源输出质量分布、已匹配比例、低质量和未匹配比例、质量集中、近似均匀或零传输、路径实际残差和额外融合用时。推理帧率是模型加官方后处理的同步时间，仪表化额外融合耗时单列。

各组按固定目标比较仅主车输入与协同输入。分析 P2 到 P3 的变化，以及同一个 P3 权重仅切换未匹配路径的变化，记录新增正确目标、丢失目标、误检变化。对新增误检的空间对应采用鸟瞰框重叠率 0.7 的一对一近似。只有邻车实点落在固定真值框内的目标单独统计，并保留目标中心格的残差读数。检测与观测证据必须同时出现，才支持独立观测解释。
