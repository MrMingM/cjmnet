# 固定 P0 权重的协同漏检诊断

海光物理卡 4。使用 LR0 第 18 轮 P0 权重。根据同一份固定 Clean 真值，选取单车在 0.7 框重叠阈值下检出、同权重协同漏检的目标。Fog 103 个，分布在 91 帧。Snow 224 个，分布在 165 帧。逐帧验证了全部目标的单车和协同状态。

## 第一次失去合格候选的位置

| 阶段 | Fog | Snow | 合计 |
|---|---:|---:|---:|
| 检测头解码后没有框达到 0.7 | 1 | 9 | 10 |
| 合格框的置信度未超过 0.20 | 47 | 163 | 210 |
| 去重移除所有剩余合格框 | 55 | 52 | 107 |
| 框尺寸、高度、范围过滤或评测目标分配 | 0 | 0 | 0 |

107 个去重失败都找到了一个得分更高、被去重保留、与被删合格框重叠超过官方去重阈值的候选。按每个目标选出的见证框计算，Fog 被删框的重叠度中位数为 0.765，保留框为 0.671。Snow 为 0.772 和 0.670。合格框最高置信度在筛选失败子集中，Fog 从单车 0.294 降到协同 0.162，Snow 从 0.314 降到 0.137，均为目标中位数。

## 局部天气点云干预

使用同一帧 Clean 点云，替换各车距离本帧诊断目标中心 12 米内、与目标框无交集的激光雷达柱体。保护范围向外扩张半个柱体对角线。逐元素核对目标相关柱体和远处柱体的输入，雷达沿用原天气输入。同帧多个诊断目标一起保护。每个目标运行单车原始天气、协同原始天气和协同替换周围三种输入。

| 天气 | 找回目标 | 原置信度失败中找回 | 原去重失败中找回 | 原定位失败中找回 |
|---|---:|---:|---:|---:|
| Fog | 26 / 103 | 8 / 47 | 18 / 55 | 0 / 1 |
| Snow | 113 / 224 | 90 / 163 | 20 / 52 | 3 / 9 |

目标覆盖格的融合前特征变化用相对 L2 幅度衡量，即特征差值长度除以原特征长度。下表是各目标中位数，三个尺度依次为 0.8、1.6、3.2 米。

| 天气 | 主车三个尺度 | 邻车三个尺度 |
|---|---|---|
| Fog | 24.7% / 23.6% / 10.8% | 28.6% / 42.5% / 28.6% |
| Snow | 18.0% / 24.0% / 3.5% | 45.9% / 64.8% / 8.2% |

目标柱体输入相同，换周围点后仍有 139 个目标被找回，且目标附近的特征在融合前已变化。该比例以已知协同丢失目标为分母，表示干预能恢复的目标比例。

## 下一轮只选质量焦点损失

合计 210 / 327 个目标先卡在置信度阈值。采用二维密集检测的质量焦点损失，用训练时预测框与真值框的鸟瞰重叠质量监督正样本分数。下一轮只替换分类损失，使用原训练和评测协议，与原始分类损失做单因素对照，统计全量 F AP70、误检及有合格框却未过置信度阈值的目标数。这个诊断已完成，正式训练属于下一轮。[Generalized Focal Loss 原论文](https://papers.nips.cc/paper_files/paper/2020/hash/f0bda020d2470f2e74990a07a607ebd9-Abstract.html)
