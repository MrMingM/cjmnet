# GRIQ v2

唯一入口为 run_all.sh。默认结果目录 /data/cjm/datasets/logs/v2xr-griq-v2。GRIQ2_OUT 可指定新数据盘上的独立可写目录。固定物理卡 1/2/3/4 分配 E1/E2/E3/E4。先运行共享真实数据检查，再在四卡上并行完成各组试跑。正式共享缓存验收后并行训练；E2 独立追加全量拟合帧。每个任务记录进程号和退出码。

V1 缓存只读，逐帧核验哈希。局部证据使用已缓存的候选框和实际点云，仅对历史帧重新计算 GSPR 逐点量。只有未缓存的训练帧运行完整 F0。固定 V1 候选池、场景分区及每帧真值。每组按批读取磁盘映射数组。场景分块估计验证集内不确定性。

选模使用训练开发场景边缘概率的平均对数损失。E1-3 权重按训练开发场景 MacroAP 选择。所有最终评分为三个边缘概率的均值，单头历史基线使用自己的严格匹配分数。阈值网格固定，校准时优先选三个 AP 均在 F0 下方 0.5 个百分点之内的配置，然后按 MacroAP 选；同分优先较好的最弱 AP 差值和接近 F0 的误检数。正式验证只报告锁定方案。E2 固定 4,000 次更新对照，另运行上限 12,000 次、每 400 步选模并允许早停的对照。局部残差使用预测框 2×3 网格，模型关闭残差时保留同权重的全框评分。局部逐格证据贡献用遮蔽该格后的条件 logit 差值度量。

断点可按原命令恢复。候选逐帧提交，训练每 400 步记录优化器和确定性采样步数，各组完成标记包含结果哈希。完成前以日志和退出码核对状态。
